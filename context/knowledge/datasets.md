# 数据集研究适用性与口径

本文件从仓库保存的 dataset-rules、cohort-and-survival 和 clinical-semantics
参考提炼。可执行边界见 medresearch.study_contract.DATASETS 和 v2 协议验证器。

- MIMIC：subject_id/患者、hadm_id/住院、stay_id/ICU stay 不互换；首次事件排序、
  年龄锚点、诊断与操作版本、药物处方/给药、时间窗与零事件分母须逐项声明。
  住院/ICU 粒度的回归需要患者聚类键，预测及 AIPW 也要求独立分组键。
- SEER8/12/17：一肿瘤不等于一患者；登记集合、release、诊断年份、分期体系、
  随访和死亡原因口径不可混用。生存时间应来自原生字段与有效性标记。
  没有匹配人口分母不能从病例数声称发病率。缺少登记集合一致性不能声称论文严格复现。
- NHANES：按参与者和周期连接组件；空腹/子样本适用性、检出限、权重周期调整和
  strata/PSU 需要单独核对。样本估计与全国总体估计严格区分。
- BRFSS：一行为某年度调查响应；跨年问卷和变量定义会变化，正式总体推断必须
  使用对应年份的权重、分层、PSU。样本数量不等于州人口，横断面关联不证明因果。

所有输入版本均为使用者声明，schema 名称不能证明实际数据 release。
统计方法可复用，不代表概念能跨数据库直接等价映射。
